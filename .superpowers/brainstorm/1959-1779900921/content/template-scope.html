What level of change do templates represent?

All three options use the exact same InvitationData from your DB — they differ in how much they visually change the invitation

A

Style presets — same layout, different look

Same sections in the same order. Templates change fonts, decorative elements, spacing, and color mood (beyond the current theme). Think "Champagne", "Garden", "Modern Black" — all the same structure, just visually distinct.

Modern Black

B

Layout templates — different structures

Each template is a fully different page design — the order, arrangement, and composition of sections changes. Hero could be split-screen or full-bleed. Details could be in cards or a timeline. The data is the same; the architecture of the page is not.

C

Both — style presets now, layout templates later

Start with style presets (lower risk, no structural change). Add a templateId field to the DB now so the door is open for full layout templates down the road. The current invitation becomes "Classic" and continues unchanged.

✦ Recommended — lowest risk, existing invitations unaffected, extensible

Key constraint

All existing live invitations must keep rendering exactly as they are today. New templates only activate when an admin explicitly selects one in the builder.
